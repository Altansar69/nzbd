Rules

  • Blocked and Failed only remove files that nzbd itself moved into the failed folder, have a valid reason record, and still match it byte for byte. Files without a reason record are counted but never purged.
  • Trash removes deleted releases, then blobs that store gc set aside once they are {{ quarantine_days }} days old (younger ones are kept), then leftovers that are provably copies of something that is still indexed.
  • Everything is audited with counts only. The same actions exist on the server: nzbd cleanup status and nzbd cleanup purge --bucket trash|blocked|failed.
